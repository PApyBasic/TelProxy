## Features

- Persian, right-to-left responsive interface
- Fetches Telegram proxy links from public sources and removes duplicates
- Search proxy servers by address
- Open a proxy directly in Telegram
- Copy a ready-to-use `t.me/proxy` link
- Approximate browser-based connectivity checks; these are not real MTProto pings
- Optional public IP and country lookup, only after the visitor presses the button
- Retry option when proxy sources cannot be reached
- Accessible status messages and reduced-motion support

## نحوه استفاده

1. [وب‌سایت TelProxy را باز کنید](https://papybasic.github.io/PAProxy).
2. صبر کنید فهرست پروکسی‌ها از منابع عمومی بارگذاری شود.
3. با کادر جست‌وجو، سرور موردنظر را پیدا کنید.
4. برای افزودن پروکسی، روی «افزودن به تلگرام» بزنید؛ یا لینک آن را کپی کنید.

## Important notes

- Proxy availability can change at any time.
- Browser checks cannot verify a full Telegram MTProto connection. Confirm whether a proxy works inside Telegram.
- The IP/country feature sends a request to a public IP lookup provider only when you choose to run the check.
- Proxy lists are fetched from third-party public repositories; TelProxy does not guarantee their availability or safety.
